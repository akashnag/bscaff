Powerful Features

Everything you need to reuse project structures

One unified CLI workflow to store, transform, and restore boilerplate, templates, and snippets.

Project Scaffolding

Save and recreate complete project structures, including nested subdirectories and files, with simple key-based commands.

bscaff --key api save dir ./api

AI-Assisted Scaffolding

Turn AI-generated project outlines copied to your clipboard straight into real folders and files instantly.

bscaff create tree ./my-app

Variable Replacement

Use {{ variable }} syntax in file names, folder names, and file contents for dynamic scaffolding.

{{ projectName }}.config.ts

Snippets & Utilities

Store multi-file code sets, URLs, or Dockerfiles. Quick-copy saved content straight to system clipboard anytime.

bscaff --key config copy

Git & Zip Repositories

Save any remote Git repo or Zip archive as a bscaff snapshot directly. Strips .git automatically.

--source git repo.git

Cross-Platform Ready

Built with Node.js to run flawlessly on Linux, macOS, and Windows with customized editor & browser preferences.

~/.bscaff/settings.yml

Getting Started

Ready in under 1 minute

1

Install via NPM

Install bscaff globally on your system using Node Package Manager.

npm install -g @akashnag/bscaff
2

Verify Installation

Ensure the binary is registered in your PATH.

bscaff --version
3

Save Your First Snapshot

Snapshot any directory and save it under a unique key name.

bscaff --key my-template save tree ./my-project

Configuration

Flexible Settings File

bscaff stores configuration in ~/.bscaff/settings.yml. You can customize text editors, web browsers, default directory exclusion patterns, and template suffixes.

Open settings instantly via bscaff settings
Default exclusions for .git, node_modules, and caches
Platform-agnostic CLI configuration
~/.bscaff/settings.yml YAML 
textEditor: nano
browser: google-chrome
exclude:
  - .git
  - .vscode
  - node_modules
  - __pycache__
  - .pytest_cache
include: []
templatesSuffix: .jinja
